# 🎂 Age Calculator Using Python

A simple Python project that calculates a person's age based on their date of birth.

---

## 📌 Features

- Calculate exact age from birth date
- Uses Python `datetime` module
- Beginner-friendly project
- Handles invalid input format
- Simple and clean code

---

## 🛠️ Technologies Used

- Python 3
- datetime module

---

```bash
age-calculator/

```

## ⚙️ How to Run

### 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/age-calculator.git
```

```bash
cd age-calculator
```

### 3️⃣ Run the Program
